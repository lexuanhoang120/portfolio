VLM-Based CCTV Video Filtering

Sejong University Vision Language Intelligence Lab · 2024.09 - Present

This project filters CCTV and non-CCTV video streams before retrieval. It uses frame sampling and prompt-based inference to improve downstream search quality.

GitHub Go to Docs

Demo

Demo flow: upload or load video → sample representative frames → run VLM prompt classification → return CCTV/non-CCTV label with confidence.

  • Input: raw mixed video sources.
  • Output: filtered list for CCTV-only retrieval.
  • Impact: faster and cleaner retrieval pipeline.

Technical Notes

  • Frame sampling to reduce inference cost.
  • Prompt templates for robust binary scene classification.
  • Integrated as a pre-filter module in the video search workflow.
